# 0.2.0 — Experimental screen warmup

Screen warmup is experimental and enabled by default. Eligible visible links are prepared in advance. Opened screens retain state and scroll position in tab memory. Pages and layouts reuse prepared CSS. API data loads on actual opening.

To disable warmup globally, merge this block into the existing layer.config.js and rebuild.

```js
export default {
    navigation: {
        warmup: {
            enabled: false
        }
    }
};
```

The page warmup option accepts `auto`, `on-demand` or `off`. Retained screen count is currently unlimited. Measure memory usage on your devices. Use activation, deactivation and disposal hooks for application timers and subscriptions. Persist restart-safe drafts in IndexedDB. Select `warmup: 'off'` for a fresh instance on every opening.

Fixes cover binary font assets in CSS, redundant warmed stylesheet loads and runtime cleanup when Service Worker registration is unavailable. The English agent skill prioritizes offline-first component development.

Run `npm install @solcorp/layer@0.2.0`, rebuild and deploy the new dist while preserving server state. Review lifecycle hooks and memory usage.

# 0.1.0 — First npm release

The first published version brings PWA development into one `@solcorp/layer` installation: CLI, compiler, browser runtime, and server packages are installed as dependencies. Application code uses JavaScript ESM in `.layer.js` with HTML/CSS templates.

Core capabilities include components and signals, file routes, server operations, PostgreSQL/PGlite and optional Redis, IndexedDB/outbox, HTTP event streams, Service Worker, and portable production bundles with Caddy.

Start with [your first application](../getting-started.md). This records the initial release, not a promise of a stable 1.x contract. Read the target release notes before upgrading.

The next release, [0.1.1](0.1.1.md), adds an automatically installed offline handbook.

# 0.1.1 — A handbook beside your application

The main package now automatically installs `@solcorp/layer-docs`: Russian and English guides, search, and highlighted examples. Open the documentation without downloading a separate website:

```bash
npx layer guide --lang en --open
```

The command starts a local handbook matching the installed framework version. Press Ctrl+C in the terminal to stop it.

The main package README explains quick start, components, and portable `dist` deployment with automatic HTTPS. Other package descriptions link to the main package and their relevant guides; repository and issue links point to public GitHub. Agent skill and VS Code extension links are included.

Version, help, and handbook commands no longer initialize server tooling unnecessarily. You do not need a configured server or database to use these commands.

To upgrade from 0.1.0, install `@solcorp/layer@0.1.1` and rebuild your application. Application APIs do not need changing. For the new startup screen, see [0.1.2](0.1.2.md).

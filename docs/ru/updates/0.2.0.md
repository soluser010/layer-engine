# 0.2.0 — Экспериментальный прогрев экранов

Прогрев экспериментальный и включён по умолчанию. Подходящие видимые ссылки подготавливаются заранее. Открытые экраны сохраняют состояние и прокрутку в памяти вкладки. Страница и layout используют подготовленные CSS. Данные API загружаются при реальном открытии.

Для полного отключения добавьте блок в существующий layer.config.js, сохранив остальные настройки, и пересоберите приложение.

```js
export default {
    navigation: {
        warmup: {
            enabled: false
        }
    }
};
```

Режим страницы `warmup` принимает `auto`, `on-demand` или `off`. Количество сохранённых экранов пока не ограничено. Измеряйте память на своих устройствах. Для собственных таймеров и подписок используйте lifecycle-хуки активации, деактивации и освобождения. Черновики для следующего запуска храните в IndexedDB. Для нового экземпляра при каждом открытии используйте `warmup: 'off'`.

Исправлены бинарные ресурсы шрифтов в CSS, повторные загрузки прогретых стилей и освобождение runtime при недоступной регистрации Service Worker. Обновлён англоязычный навык агента для offline-first, компонентной разработки.

Выполните `npm install @solcorp/layer@0.2.0`, пересоберите приложение и разверните новый dist с сохранением каталога серверного состояния. Проверьте lifecycle-хуки и расход памяти.

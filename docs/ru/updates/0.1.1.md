# 0.1.1 — Руководство рядом с приложением

В этой версии основной пакет автоматически устанавливает `@solcorp/layer-docs`: руководство на русском и английском, поиск и подсветку примеров. Открывайте документацию без отдельной загрузки сайта:

```bash
npx layer guide --lang ru --open
```

Команда запускает локальное руководство. Оно соответствует установленной версии фреймворка; для завершения используйте Ctrl+C в терминале.

README основного пакета объясняет быстрый старт, создание компонентов и запуск переносимого `dist` с автоматическим HTTPS. Описания остальных пакетов ведут к основному пакету и профильным разделам; репозиторий и issues указывают на публичный GitHub. Добавлены ссылки на навык агента и расширение VS Code.

Команды версии, справки и руководства больше не инициализируют серверные инструменты без необходимости. Для работы с этими командами не нужно настраивать сервер или БД.

Для обновления с 0.1.0 установите `@solcorp/layer@0.1.1` и пересоберите приложение. Изменять его API не требуется. Если нужна новая функциональность стартового экрана, смотрите [0.1.2](0.1.2.md).

# 0.1.0 — Первый npm-выпуск

Первая опубликованная версия объединяет разработку PWA в одной установке `@solcorp/layer`: CLI, compiler, browser runtime и серверные пакеты устанавливаются как зависимости. Прикладной код пишется на JavaScript ESM в `.layer.js` с HTML/CSS-шаблонами.

Основные возможности: компоненты и signals, файловые маршруты, серверные operations, PostgreSQL/PGlite и необязательный Redis, IndexedDB/outbox, события через HTTP-поток, Service Worker и переносимый production bundle с Caddy.

Начните с [первого приложения](../getting-started.md). Это история начального выпуска, а не обещание стабильного контракта 1.x. Перед обновлением читайте заметки целевой версии.

Следующий выпуск [0.1.1](0.1.1.md) добавляет автоматически устанавливаемое офлайн-руководство.

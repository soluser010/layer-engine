# 0.2.1 — Важное обновление безопасности

Закрыта возможность чтения файлов за пределами проекта через dev-сервер. Усилены проверки при сборке и генерации клиентского API. Production-сборка включает Caddy 2.11.9 и сохраняет длительные потоки событий. Обновите CLI и пересоберите приложение.

- **Dev-сервер и сборка.** Сервер отдаёт файлы только из разрешённого каталога. При сборке компоненты, CSS и ресурсы проверяются и читаются через один файловый дескриптор. Файлы окружения исключаются из сборки. Для временной сборки и отката создаются отдельные каталоги. Если восстановление прервалось, резервная копия сохраняется.
- **Операции и PostgreSQL.** Генератор клиентских методов проверяет имена, типы, схемы, зарезервированные поля и совпадения имён в JavaScript и декларациях типов. Некорректный контракт останавливает сборку с диагностикой. Драйвер PostgreSQL обновлён с 8.16.3 до 8.23.1. В testkit специальные JSON-ключи обрабатываются как собственные поля данных.
- **Production и события.** Официальные архивы Caddy 2.11.9 закреплены по SHA-512 для четырёх платформ. Обновление включает исправления обработки путей, заголовков прокси и настроек TLS. Параметр `write_idle 30s` ограничивает зависшую запись клиенту. Поток POST может ждать следующего события дольше 30 секунд.
- **Авторизация.** Уточнены обязанности приложения при создании управляемых аккаунтов, проверке одноразового кода телефона и хранении закрытых ключей OAuth. Открытые ключи проверки доступны через `jwks_uri`.
- **Проверки поставки.** Добавлены проверки fast-check, CodeQL и Gitleaks, проверки изоляции tenant и архивов пакетов. Проверка npm использует официальный реестр, CI сохраняет перечень зависимостей CycloneDX. Исправлен тестовый стенд live reload и добавлена проверка длительного потока через настоящий Caddy. Уточнены сведения о лицензиях зависимостей Lightning CSS и Web Push.

## Обновление

Выполните команды в каталоге приложения.

```sh
npm install @solcorp/layer@0.2.1
npm run build
```

Разверните новый `dist` и перезапустите приложение, сохранив прежний каталог состояния. Уже развёрнутый bundle использует прежний Caddy до замены.

[Caddy 2.11.9](https://github.com/caddyserver/caddy/releases/tag/v2.11.9) · [PostgreSQL](../database-runtime.md)

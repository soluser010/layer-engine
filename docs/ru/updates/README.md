# История обновлений Layer-Engine

[0.2.0 — Экспериментальный прогрев экранов](0.2.0.md)

Здесь собраны изменения, важные при разработке приложений: новое поведение, настройки и действия при обновлении. Существующие статьи руководства описывают актуальные API, а эта папка сохраняет историю.

| Версия | Основные изменения |
| --- | --- |
| [0.1.2](0.1.2.md) | Экран первой установки PWA, компактная карточка обновления и история версий в руководстве |
| [0.1.1](0.1.1.md) | Офлайн-документация RU/EN, команда `layer guide` и улучшенное описание пакетов |
| [0.1.0](0.1.0.md) | Первая опубликованная версия полного набора пакетов |

Версия 0.1.2 подготовлена к публикации. Наличие страницы в GitHub не означает, что версия уже доступна в npm. Доступность проверяется командой `npm view @solcorp/layer@0.1.2 version`. Установка без версии использует тег `latest`, который обновляется отдельно.

Сначала прочитайте статью нужной версии, затем обновите зависимость приложения и пересоберите `dist`. Не заменяйте отдельные файлы в уже собранном приложении.

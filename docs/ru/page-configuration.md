# Все настройки страницы

[Карта возможностей](capabilities.md) · [Полные сигнатуры и типы](api-reference-router.md)

Объект `page` статический и читается compiler без исполнения произвольного JavaScript. Неизвестные поля и неподдерживаемые значения отклоняются с `ROUTE_MANIFEST_INVALID`. Фабрика возвращает неизменяемый верхний объект, но сама не подключает router. Полные примеры: [SSR](routing-ssr.md), [CSR](routing-csr.md).

## Все параметры

| Поле | Тип / значения | Default | Действие |
| --- | --- | --- | --- |
| `render` | `'ssr' / 'csr'` | `ssr` | Пререндер статического URL при build либо создание DOM в браузере. |
| `layout` | `string / null` | `inherited / null` | Имя `[a-z][a-z0-9-]{0,79}`. Внешняя оболочка с одним outlet. |
| `auth` | `'session' / 'none'` | `session` | Проверка authenticated в router; не защита опубликованного HTML. |
| `permissions` | `string[]` | `[]` | Уникальные dotted names; все должны быть в identity.permissions. |
| `preload` | `string[]` | `[]` | Уникальные имена операций; вызываются последовательно через runner приложения. |
| `guard` | `string / null` | `null` | Dotted name; вызывается через guardRun после permissions. |
| `offline` | `'deny' / 'shell' / 'snapshot' / 'local'` | `deny` | deny блокирует offline-переход. Остальные разрешают продолжить; снимки/локальные данные не создаются автоматически. |
| `cache` | `'private' / 'public' / 'no-store'` | `private` | В текущем pipeline это metadata: не переключает HTTP headers, SW или сохранение DOM. |
| `warmup` | `auto / on-demand / off` | `auto` | Подготовка по видимости, по переходу или исключение из подготовки и хранения. |
| `metadata` | `object` | `{}` | Только перечисленные ниже строковые поля; без секретов. |

## Как выбрать режим прогрева страницы

В файле `*.layer.js` укажите `warmup` в **именованном экспорте `page`**. Он управляет всей страницей, включая вложенные компоненты. Экспорт по умолчанию задаёт её содержимое. Ниже полный пример публичной страницы «О приложении».

```js
// src/pages/about.layer.js
import {html, layerComponentCreate, layerPageCreate} from '@solcorp/layer';


export const page = layerPageCreate({
    render: 'ssr',
    auth: 'none',
    warmup: 'auto'
});

export default layerComponentCreate(function AboutPage(){
    //Render the public screen when the router opens it.
    return html`<main><h1>О приложении</h1></main>`;

});
```

Для другого поведения измените одно поле в `layerPageCreate`. Выбирайте его для **страницы назначения**: чтобы настроить открытие чата из списка, укажите режим в файле чата.

| Значение `warmup` | Пока ссылка видна | При первом переходе | При возврате в той же вкладке |
| --- | --- | --- | --- |
| `'auto'` (по умолчанию) | После 250 мс непрерывной видимости подходящая ссылка попадает в очередь. Layer подготавливает ресурсы и статические элементы. | Использует готовую часть, остальное готовит при переходе. Подходит для разделов главного меню. | Может восстановить экземпляр, локальное состояние и прокрутку. |
| `'on-demand'` | Ссылка сама по себе ничего не запускает. | Выбор чата или вызов `navigate()` запускает подготовку. Для ожидания первой порции сообщений добавьте хук приложения. | Экземпляр можно восстановить так же, как при `'auto'`. |
| `'off'` | Фоновой подготовки нет. | Создаёт экран при открытии. Подходит для оплаты или одноразовой формы. | При уходе экземпляр освобождается. Следующее открытие создаёт новый. |

**Пример выбора.** У ссылки на обзор в основном меню оставьте странице обзора `warmup: 'auto'`. Для маршрута чата задайте `warmup: 'on-demand'`, если даже отдельная ссылка на него с главной должна ждать выбора пользователя. Для экрана оплаты задайте `warmup: 'off'`, если возврат должен начинаться с нового экземпляра формы. На сервере всё равно проверяйте статус платежа.

**Почему видимая ссылка может ждать клика.** При `'auto'` ссылки в HTML- и ARIA-списках и во вложенном контейнере с реальной вертикальной прокруткой готовятся по требованию. Обычный контейнер с `overflow-y: auto`, в котором всё помещается, допускает фоновую подготовку. Явный `target="_self"` делегирует переход браузеру.

**Область действия.** В `layer.config.js` параметр `navigation.warmup.enabled` по умолчанию равен `true`. Если установить `false` и пересобрать приложение, очередь и сохранение экранов отключатся для всех страниц, включая страницы с явным `'auto'`. Хук подготовки данных по-прежнему вызывается при открытии. Параметр `render` отдельно определяет SSR/CSR, а `cache: 'no-store'` сам по себе не освобождает экземпляр страницы.

Сохранение действует в памяти текущей вкладки при подходящем контексте доступа. После перезагрузки документа экран создаётся заново. Для черновика, который должен пережить перезапуск приложения, используйте [IndexedDB](indexeddb.md). [Пример чата, хук перед показом и диагностика](routing.md#экспериментальный-прогрев-экранов).

## Metadata

| Поле metadata | Максимум символов |
| --- | --- |
| `title` | 200 |
| `description` | 500 |
| `robots` | 200 |
| `canonical` | 2048 |
| `author` | 200 |
| `keywords` | 500 |
| `themeColor` | 100 |
| `colorScheme` | 100 |
| `applicationName` | 200 |
| `language` | 35 |
| `direction` | 4 |
| `openGraphTitle` | 200 |
| `openGraphDescription` | 500 |
| `openGraphType` | 100 |
| `openGraphUrl` | 2048 |
| `openGraphImage` | 2048 |
| `openGraphImageAlt` | 500 |
| `openGraphSiteName` | 200 |
| `openGraphLocale` | 35 |
| `twitterCard` | 30 |
| `twitterTitle` | 200 |
| `twitterDescription` | 500 |
| `twitterImage` | 2048 |
| `twitterImageAlt` | 500 |

Все значения — непустые строки без C0/DEL. Максимум 24 поля. URL-поля `canonical`, `openGraphUrl`, `openGraphImage`, `twitterImage`: HTTP(S) либо root-relative путь, не `//host`. `direction`: `auto`, `ltr`, `rtl`; `twitterCard`: `app`, `player`, `summary`, `summary_large_image`; `language`: языковой тег вида `ru-RU`. Значения применяются к документу, а не к manifest PWA.

## Подключение guard и preload

В `src/app.js` объявите `guardRun(name, {route, params, identity})`, возвращающий строго `true` для разрешения. `false`/объект дают `forbidden`; строка становится статусом отказа. Объект `{redirect: ...}` не выполняет переход; нужную навигацию реализует приложение. Проверку прав данных обязательно повторяет сервер. `preload(operationName, {params})` возвращает значение или Promise; результат доступен странице в `context.route.preload[operationName]`. Это не автоматическое заполнение query cache. Укажите собственное преобразование params в payload операции. Без runner заявленная возможность завершается ошибкой, а не пропускается.

## Совместимость

Нельзя считать `null` универсальным способом отключения: для layout применяется наследование через `??`; `null` не сбрасывает унаследованный layout. Выбирайте явный layout или структуру маршрутов без наследования. По изменению настроек выполните новую сборку.
